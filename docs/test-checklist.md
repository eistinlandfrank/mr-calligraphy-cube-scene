# 测试清单

> 每次答辩或发布前，先运行 `npm run test:smoke` 和 `npm run build`，再按本清单完成浏览器检查。

## 前台流程

- [ ] 打开 `/demo`，点击“开始”，确认状态从 `idle` 进入 `ready_check`。
- [ ] 依次推进到 `practice_game`，确认老人端书法练习出现。
- [ ] 完成或点击完成作品，确认进入 `scoring`、`report`、`caregiver_confirm`。
- [ ] 点击确认结束，确认进入 `finished`，并可重置或重来。

## 书法游戏

- [ ] 使用贴近标准路径的轨迹完成一轮，记录综合分。
- [ ] 使用明显偏离标准路径或节奏过快/过慢的轨迹完成一轮，确认分数更低。
- [ ] 起笔偏离当前笔画，确认出现笔顺提醒。
- [ ] 点击重播当前笔画，确认轨迹清空并记录重写次数。

## 护工联动

- [ ] 护工端点击暂停，确认老人端动画与流程暂停。
- [ ] 护工端点击继续，确认流程恢复。
- [ ] 护工端点击结束体验，确认进入报告或完成状态。
- [ ] 护工端点击呼叫老人，确认老人端/控制台出现提示。
- [ ] 老人端点击求助护工，确认护工端安全状态变为“老人求助”。

## 后台编辑

- [ ] 打开 `/admin`，切换不同场景，确认对象树和视窗同步。
- [ ] 修改对象 position、rotation、scale、颜色和透明度，确认视窗实时变化。
- [ ] 新增、复制、删除对象，确认对象树和视窗同步更新。
- [ ] 点击保存到本机，刷新页面后确认配置不丢失。
- [ ] 保存多个版本，使用版本下拉切换，确认场景回到对应版本。

## 导入导出

- [ ] 导出当前 SceneConfig JSON，再导入该文件，确认场景一致。
- [ ] 导出项目配置，确认 payload 包含 project、flow 和 scenes。
- [ ] 导入缺字段或格式错误的 JSON，确认页面显示明确错误。
- [ ] 导入 FlowConfig JSON，确认前台状态机按新流程运行。
