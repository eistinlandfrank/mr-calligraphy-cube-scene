# Codex 开发任务

本项目按功能逐步提交，每个任务完成后使用中文 commit 信息推送到 GitHub。

## 已规划任务

1. 建立 React + Vite 基础项目。
2. 建立 SceneConfig 数据结构和示例 JSON。
3. 实现前台胶囊舱 Demo。
4. 实现后台 3D 场景编辑器 MVP。
5. 加入可复用护工监护端 UI。
6. 加入虚拟书法游戏。

## 验收方式

- 每个任务至少通过 `npm run build`。
- 涉及 3D 或前端界面时，使用浏览器打开本地页面检查主要视图。
- 每次提交前确认 `git status` 中只包含当前任务相关文件。
